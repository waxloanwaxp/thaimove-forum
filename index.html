เชื่อมต่อฐานข้อมูลออนไลน์ (Firebase Config)

วิธีนำค่า Config จาก Firebase Console มาเชื่อมต่อ:

1. เข้าไปที่โปรเจกต์ของคุณใน Firebase Console > Project Settings (รูปฟันเฟือง) > Your apps > Web (</>)

2. คัดลอกโค้ด const firebaseConfig = { ... }; มาวางในช่องด้านล่างแล้วกดบันทึก

3. หากต้องการให้ทุกคนที่เปิดเว็บเชื่อมต่ออัตโนมัติ ให้เปิดไฟล์ index.html ค้นหา DEFAULT_FIREBASE_CONFIG = null แล้ววางค่าแทนที่ null ก่อนอัปโหลดขึ้น GitHub
