
# ชุด Prompt สำหรับสั่งงาน AI ให้อัปโหลดโปรเจกต์ขึ้น GitHub

เลือกก๊อปปี้ Prompt ด้านล่างนี้ไปวางใน **Claude Code**, **Cursor**, **Windsurf** หรือ **Terminal AI** ตามสถานการณ์ของคุณได้เลยครับ

## แบบที่ 1: อัปโหลดโปรเจกต์ขึ้น GitHub Repository ใหม่ (แนะนำ)

*ใช้เมื่อโฟลเดอร์โปรเจกต์ในเครื่องยังไม่ได้เชื่อมต่อกับ GitHub มาก่อน*

```
ช่วยจัดการนำโปรเจกต์ทั้งหมดในโฟลเดอร์ปัจจุบันอัปโหลดขึ้น GitHub ของฉันให้เรียบร้อย โดยมีขั้นตอนดังนี้:

1. ตรวจสอบและเตรียมไฟล์ให้พร้อมก่อนอัปโหลด:
   - ตรวจสอบว่ามีไฟล์ `.gitignore` ที่เหมาะสมกับโปรเจกต์นี้หรือไม่ ถ้ายังไม่มีให้สร้างไฟล์ `.gitignore` เพื่อป้องกันการอัปโหลดไฟล์ขยะหรือไฟล์ความลับ (เช่น `.env`, `node_modules/`, `.DS_Store`, `Thumbs.db`)
   - หากมีไฟล์ HTML หลักสำหรับหน้าแรก (เช่น `vehicle-service-forum.html`) และยังไม่มี `index.html` ให้สร้างหรือคัดลอกเป็น `index.html` เพื่อรองรับการเปิดเว็บผ่าน GitHub Pages
   - สร้างไฟล์ `README.md` ภาษาไทยที่สรุปภาพรวมของโปรเจกต์ ฟีเจอร์หลัก และวิธีใช้งาน

2. เริ่มต้นใช้งาน Git และสร้าง Repository บน GitHub:
   - รันคำสั่ง `git init` และตั้งค่า Branch หลักเป็น `main` (`git branch -M main`)
   - สร้าง GitHub Repository ใหม่แบบ Public (ตั้งชื่อตามโฟลเดอร์โปรเจกต์ หรือชื่อ `thaimove-forum`) โดยใช้ GitHub CLI (`gh repo create`) หรือ GitHub MCP Tool
   - ทำการ `git add .` และ `git commit -m "Initial commit: upload project files"`
   - Push โค้ดทั้งหมดขึ้นไปยัง Branch `main` (`git push -u origin main`)

3. เปิดใช้งาน GitHub Pages (หากเป็นโปรเจกต์เว็บ Static):
   - เปิดใช้งาน GitHub Pages จาก Branch `main` โฟลเดอร์ `/ (root)` และแสดงลิงก์ URL ของ Repository รวมถึงลิงก์หน้าเว็บไซต์ที่ใช้งานได้จริงให้ฉันทราบเมื่อเสร็จสิ้น


```

## แบบที่ 2: อัปโหลดโค้ดขึ้น Repository ที่มีอยู่แล้วบน GitHub

*ใช้เมื่อคุณสร้าง Repository เปล่าๆ ไว้บนหน้าเว็บ GitHub แล้ว และมีลิงก์ URL ของ Repo*

```
ช่วยนำไฟล์โปรเจกต์ทั้งหมดในโฟลเดอร์ปัจจุบันอัปโหลดขึ้นไปยัง GitHub Repository ที่มีอยู่แล้วตามลิงก์นี้:
[วางลิงก์ GitHub Repository ของคุณที่นี่ เช่น https://github.com/username/repo-name.git]

โดยดำเนินการตามขั้นตอนนี้:
1. สร้าง `.gitignore` เพื่อกรองไฟล์ที่ไม่จำเป็นออก
2. รัน `git init` และตั้งค่า Branch เป็น `main`
3. เชื่อมต่อ Remote origin เข้ากับลิงก์ Repository ด้านบน
4. รัน `git add .` และ `git commit -m "Initial commit"`
5. สั่ง `git push -u origin main` (หากบน GitHub มีไฟล์เริ่มต้นอยู่แล้วให้ดึงมารวมหรือจัดการให้เรียบร้อยโดยไม่ให้โค้ดในเครื่องสูญหาย) และสรุปผลการทำงานให้ทราบ


```

## แบบที่ 3: อัปเดตการแก้ไขล่าสุดขึ้น GitHub (Push Update)

*ใช้เมื่อเคยอัปโหลดโปรเจกต์ขึ้น GitHub ไปแล้ว และต้องการส่งไฟล์ที่แก้ไขใหม่ขึ้นไปอัปเดต*

```
ช่วยตรวจสอบไฟล์ที่มีการแก้ไขล่าสุดในโปรเจกต์นี้ (`git status` และ `git diff`) จากนั้น:
1. เขียน Commit Message ภาษาอังกฤษที่สื่อความหมายชัดเจนตามสิ่งที่แก้ไขจริง
2. ทำการ Stage ไฟล์ทั้งหมด (`git add .`) และ Commit การเปลี่ยนแปลง
3. สั่ง `git push` ขึ้นไปยัง GitHub Repository ปัจจุบัน และรายงานสรุปรายการไฟล์ที่ถูกอัปเดตขึ้นไปให้ทราบ


```
